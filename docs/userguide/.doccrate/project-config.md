# Project Config

This page stores project-level values used while rendering the documentation.

## Variables

| name | value | description |
|---|---|---|
| product | Prose | Product or documentation set name |
| paginate_for_pdf | on | This is a printed guide; paginate it |
| page_size | a4 | PDF page size: a4 or letter |
| page_orientation | portrait | PDF page orientation: portrait or landscape |
| header_enabled | on | Draw export header text from page 2 onwards |
| header_text_left | {{product}} User Guide | Optional left header text |
| header_text_right | {{MONTHYEAR}} | Optional right header text |
| footer | on | Draw a footer rule on exported pages |
| footer_text | {{product}} 0.1 | Optional text shown below the footer rule |
| docheader | on | Include the standard document cover banner |
| docheader_text | {{product}} User Guide | Document cover banner title |
| doctrailer | off | No final-page trailer banner |
| doctrailer_text | | Final-page trailer title |
| doctrailer_materials_heading | | Right trailer materials heading |
| doctrailer_materials | | Right trailer materials text column |
| spelling_enabled | off | Spelling checks stay off for this draft |
| spelling_locale | en-GB | English spelling dialect |
| spelling_mode | off | off, warn, or strict |
| doctrailer_legal | | Left trailer trademark and legal text column |
