# The Keyboard

While the Prose window is active, **every key goes to Prose.** The machine is
a whole computer and the window is its keyboard: ⌘ is Prose's Command key and
⌥ its Option key, so the shortcuts you know from the Mac work inside the
machine, on the machine's own terms.

The window's own shortcuts — the ones the Mac side answers to — add Control
to Command:

| Shortcut | The window's action |
|---|---|
| ⌃⌘F | Enter or leave full screen |
| ⌃⌘P | Pause or resume |
| ⌃⌘R | Restart |
| ⌃⌘S | Screenshot |
| ⌃⌘T | Show or hide the toolbar |
| ⌃⌘/ | Show or hide the status bar |
| ⌃⌘0 | Actual size |
| ⌃⌘H | Hide Prose |
| ⌃⌘M | Minimize |
| ⌃⌘? | The keyboard summary (Help menu) |

There is no ⌃⌘Q by design: that chord belongs to the Mac, and Quit has none —
closing the window shuts Prose down anyway.

Keys a Mac keyboard cannot type are in **Machine ▸ Send Keys**:
Control-Alt-Delete, which opens the guest's Team Monitor, and Print Screen.
